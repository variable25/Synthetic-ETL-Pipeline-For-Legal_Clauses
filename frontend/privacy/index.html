Privacy

Last updated 6 October 2026

Who runs this site

This is a personal, non-commercial demo project run by Abhishek Kalakbandi Sridhar. Contact: sridharabhishek7@gmail.com.

The text you classify

When you press Classify, your clause is sent to the server, classified in memory by the model, and the result is sent back. The text is not written to a database, a file or the logs, and it is not used to train the model.

Server logs

The site runs on Google Cloud Run in Frankfurt (europe-west3). Like any web server, it records basic request data: IP address, time, requested path, browser user agent and response status. For each classification the app also logs the predicted label, the text length and the response time, never the text itself. Google Cloud deletes these logs after 30 days. Google processes this data on our behalf under its Cloud Data Processing Addendum.

The legal basis is our legitimate interest in running the site securely and knowing whether it works (Art. 6(1)(f) GDPR).

Cookies and tracking

This site sets no cookies, uses no browser storage and loads no third-party scripts or fonts. That is why there is no cookie banner.

Your rights

You can ask for access to, correction or deletion of data about you, and object to its processing, by writing to the contact above. You can also complain to a data protection supervisory authority.
